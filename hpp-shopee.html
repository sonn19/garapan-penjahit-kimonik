1. Impor item produk Shopee

Gunakan file Excel Penghasilan yang memiliki kolom Qty/Jumlah barang. Hanya baris Sku yang diambil, bukan baris Order. Jika file tidak memiliki kolom Qty, impor akan ditolak agar perhitungan laba tidak keliru. Nomor pesanan lama tidak berubah.

2. Cocokkan produk dan HPP otomatis

Untuk setiap item, pilih Master Produk Kimonik. HPP aktif disimpan sebagai snapshot ketika dipasangkan. Item tanpa HPP tetap ditandai belum lengkap.

Periksa Qty untuk setiap produk. Setelah SQL jumlah item diaktifkan, ubah angka lalu klik Simpan Qty. Pembukuan otomatis menghitung HPP × Qty.
